# Balloon Room (Godot 4 3D)

A high-performance 3D incremental/idle physics game built in **Godot 4.x (Jolt Physics)**.

## Features
- **1,000,000 Balloon Grand Goal**: Deep progression tree with real-time countdown, prestige Rebirth loop with Helium multipliers.
- **6 Dynamic Room Expansions**: From Small Room (16x16m) to Hyper Lab (95x95m) with automatic geometric reshaping and dynamic ceiling matrices.
- **Automation Devices**: Spikes, High-Voltage Electric Grid, Roller Conveyor Crusher, Sentry Drones, Gravity & Gas Regulators, and Magnet Pylons.
- **C++ Direct Space State Physics**: 60-120+ FPS at 1,500+ active rigid body balloons.
- **Elemental Balloon Types**: Bombs with burning fuses, Golden balloons with halo rings, and Plasma chain-reaction balloons.

## Controls
- **WASD**: Movement
- **Shift**: Sprint
- **Left Click**: Pop Balloon (Hold for Auto-Pop)
- **Right Click**: Nudge Air Blower
- **E**: Interact (Aim with crosshair to open Shop, change Gravity, or relocate Devices)
- **G**: Cycle Gravity Mode
- **Tab / Esc**: Menu / Cursor
